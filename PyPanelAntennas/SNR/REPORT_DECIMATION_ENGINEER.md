> **Эксперимент:** `exp_decimation_analysis.py` | **Дата:** 2026-04-10
> **Сигнал:** CW, f_norm=0.15, N_input=1 300 000 complex float32
> **Метод:** CA-CFAR, Hann window, guard=5, ref=16

## 1. Постановка задачи

В системе обработки сигналов поступает поток из **1.3 миллиона** комплексных отсчётов
(после дечирпа LFM). FFT такой длины нецелесообразен из-за памяти и латентности.
Вопрос: **можно ли прореживать (decimating) поток без потери качества классификации
SNR на ветви Low / Mid / High?**

---

## 2. Математическая модель

### 2.1 CFAR SNR в частотной области

Для CW-тона `x[n] = A·exp(j·2π·f₀·n) + w[n]` (w[n] ∼ CN(0, σ²))
после применения **Hann-окна** к `N_actual` отсчётам и FFT размером `N_fft ≥ N_actual`:

```
Пик в бине k₀:    |X[k₀]|²  ≈  A² · (N_actual / 2)²
Шум в соседних:   E[|X[k]|²] =  σ² · N_actual · 3/8    (ENBW Hann = 3/8)

CFAR SNR (linear) = peak / noise_per_bin
                  = A² · N_actual · (2/3) / σ²
                  = SNR_input_linear · N_actual · (2/3)
```

В децибелах:

```
┌─────────────────────────────────────────────────────────────────┐
│  CFAR_SNR_dB = SNR_input_dB + 10·log₁₀(N_actual) − 1.76 dB    │
│                               ──────────────────   ─────────    │
│                               processing gain      Hann loss    │
└─────────────────────────────────────────────────────────────────┘
```

### 2.1.1 Физический смысл CFAR_SNR — почему «оценка 35.5 dB» при входном SNR 5 dB?

Это ключевой вопрос интерпретации. **CFAR_SNR ≠ SNR_input.**

CFAR_SNR — это отношение мощности **пика в FFT-спектре** к **среднему шуму в reference-bins**.
Он включает в себя processing gain от когерентного накопления в FFT.

#### Механизм когерентного / некогерентного накопления

Для сигнала `x[n] = A·exp(j·2π·f₀·n) + w[n]` при суммировании в FFT-бине k₀:

```
Сигнальная часть (когерентно):
  X_sig[k₀] = A · Σ w_h[n] · e^{j·2π·(f₀−k₀/N)·n}
             ≈ A · Σ w_h[n]    (при f₀·N = k₀, целый бин)
             = A · N_actual/2   (сумма Hann-окна ≈ N/2)

  Пик мощность: |A · N/2|² = A² · N²/4   →  растёт как N²

Шумовая часть (некогерентно, каждый отсчёт независим):
  E[|X_noise[k]|²] = Σ |w_h[n]|² · σ²
                    = σ² · 3N/8             (ENBW Hann = 3/8)
                                             →  растёт как N

Отношение (CFAR SNR):
  peak / noise_per_bin = A²·N²/4 / (σ²·3N/8)
                       = (A²/σ²) · N · (2/3)
                       = SNR_input_linear · N_actual · (2/3)
```

Processing gain в дБ при N_actual=2048:

```
  G = 10·log₁₀(2048 · 2/3) = 10·log₁₀(1365) = 31.4 dB
```

Числовая проверка (SNR_input = 5 dB):

```
  SNR_input_linear = 10^(5/10) = 3.162
  CFAR_SNR_linear  = 3.162 · 2048 · 2/3 = 4317
  CFAR_SNR_dB      = 10·log₁₀(4317) = 36.35 dB
  Измерено:                             35.50 dB  (расхождение 0.85 dB — шум + scalloping)
```

#### Таблица: CFAR_SNR → входной SNR при N_fft=2048

| CFAR выход (дБ) | Входной SNR (дБ) | Ветка решения |
|:---------------:|:----------------:|:-------------:|
| < 15            | < −16.4          | **Low**   (чистый шум) |
| 15 … 30         | −16.4 … −1.4     | **Mid**   (слабый сигнал) |
| ≥ 30            | ≥ −1.4           | **High**  (детектируемый сигнал) |
| 35.5            | ≈ 5              | High ✓ |
| 50.4            | ≈ 20             | High ✓ |
| 80.2            | ≈ 50             | High ✓ |

> Пороги 15/30 dB уже включают в себя processing gain.
> Менять N_fft без перекалибровки порогов — ошибка.

---

### 2.2 Влияние прореживания

При шаге прореживания `D = ceil(N_samples / target_n_fft)`:

```
N_actual = N_samples // D  ≈  target_n_fft

Delta_dB = CFAR_SNR(decimated) − CFAR_SNR(baseline)
         = 10·log₁₀(N_actual_decimated / N_actual_baseline)
         = −10·log₁₀(D)
```

**Критически важно:** `Delta_dB` не зависит от входного SNR.
Для всех SNR_in ∈ [5..50 dB] потеря одинакова = −10·log₁₀(D).

### 2.3 Прореживание комплексного сигнала — теорема

Для комплексного базовополосного CW `A·exp(j·2π·f₀·n)` прореживание без
anti-aliasing фильтра **не меняет амплитуду и дисперсию шума**:

```
y[k] = x[k·D] = A·exp(j·2π·f₀·D·k) + w[k·D]
```

Новая нормированная частота: `f_new = (f₀ · D) mod 1` — сигнал «перемещается»
по спектру, но **амплитуда A и σ² сохраняются**. Обнаружение CFAR работает
корректно в любом бине.

### 3.2 Феномен насыщения по боковым лепесткам

Baseline при N_actual=1 300 000 даёт **≈55 dB для ВСЕХ SNR_in от 5 до 50 dB**.
Это не ошибка — это физическое насыщение CFAR.

**Объяснение:**

```
Боковой лепесток Hann в reference-bins (бины k₀±6..21 при step=1):
  Первый сайдлоб:  −31.5 dB от пика
  В абсолютных единицах при N=1.3M:
    Power_sidelobe = A² · (N/2)² · 10^(−31.5/10)

  Шум в том же бине:
    Power_noise    = σ² · 3·N/8

  Порог насыщения: Power_sidelobe = Power_noise
  → SNR_linear · N · sidelobe_frac = 3/2
  → для N=1.3M: SNR_input ≈ −4 dB (!)
```

Для всех SNR_input > −4 dB боковые лепестки **сильнее шума в reference-bins**.
CFAR измеряет не шум, а боковые лепестки → насыщение ~55 dB.

**Следствие:** большой N_fft (>256K) не даёт преимуществ для классификатора.

Для высоких SNR разброс увеличивается из-за несовпадения частоты с центром бина
(scalloping loss Hann = до 1.4 dB, но при разных шагах множится).

## 4. Рекомендации по децимации

### 4.1 Итоговая таблица — режимы работы

| Режим | target_n_fft | Шаг прореживания | Gain от N | Точность | Применимость |
|-------|:------------:|:----------------:|:---------:|:--------:|:-------------|
| Оптимальный    | **2048**   | ≈635 (от 1.3M)  | +31.4 dB  | ✅ Высокая | SNR_in ≥ −16 dB, все сигналы |
| Расширенный    | **4096**   | ≈317            | +34.4 dB  | ✅ Хорошая | SNR_in ≥ −19 dB |
| Максимальный   | **8192**   | ≈159            | +37.4 dB  | ⚠️ Линейная зона только SNR≤20 dB |
| Избыточный     | >65 536    | <20             | насыщение | ❌ Нет смысла | боковые лепестки доминируют |
| Без децимации  | 1 048 576+ | 1               | насыщение | ❌ Нет смысла | 100× медленнее, нет выигрыша |

### 4.2 Главная рекомендация

```
┌──────────────────────────────────────────────────────────────────────┐
│  ✅ ДЕЦИМАЦИЯ ДОПУСТИМА И РЕКОМЕНДОВАНА для 1.3M → target_n_fft=2048 │
│                                                                       │
│  Прореживание в D ≈ 635 раз НЕ портит классификацию Low/Mid/High    │
│  потому что пороги (15 dB / 30 dB) откалиброваны под N_fft=2048.    │
│                                                                       │
│  Допустимый диапазон: target_n_fft ∈ [1024, 8192]                    │
│    - 1024: минимум, работает при SNR_in > −13 dB                     │
│    - 2048: оптимум (откалиброванные пороги)                           │
│    - 4096: запас точности, +3 dB обнаруживаемость                    │
│    - 8192: только если нужна экстра-чувствительность к слабым сигналам│
│                                                                       │
│  ЗАПРЕЩЕНО: target_n_fft > 65536 — нет выигрыша, сайдлоб-насыщение  │
└──────────────────────────────────────────────────────────────────────┘
```

### 4.3 Критерий выбора target_n_fft

Для системы с минимально ожидаемым SNR_in_min:

```python
# SNR_input_min — минимальный входной SNR в дБ
# CFAR_min = порог детектора = 15 dB (Low→Mid)

N_actual_min = 10 ** ((CFAR_min - SNR_input_min + 1.76) / 10)
# +1.76 — поправка Hann, запас +3 dB в числителе

# Пример: SNR_input_min = -10 dB, CFAR_min = 15 dB
N_actual_min = 10 ** ((15 + 10 + 1.76) / 10) ≈ 10^2.676 ≈ 475
→ target_n_fft ≥ 512 (следующая степень двойки)
```

### 4.4 Почему децимация безопасна для комплексных сигналов

В отличие от вещественных сигналов, **комплексный базополосный сигнал**:
- Не имеет «зеркальных» alias'ов при прореживании
- Шум после прореживания остаётся белым с той же дисперсией σ²
- Сигнал просто меняет нормированную частоту: `f_new = (f₀·D) mod 1`
- CFAR всегда находит пик через `argmax` независимо от его положения

(инструментальная погрешность: шум + scalloping). В нелинейной зоне (N_fft > 131072)
пучок расширяется до 8–12 dB.

#### Панель 2 (правая) — Абсолютные значения CFAR SNR: параллельная структура

**Оси:**
- X: `log₂(N_fft_actual)` ∈ [10..20]
- Y: CFAR SNR (дБ), абсолютные значения

**Элементы:**
- 10 цветных сплошных линий — измерения
- 10 цветных пунктирных линий — теоретическая формула
- Горизонтальная белая пунктирная линия: y = 0 (ориентир)
- Легенда: 10 уровней SNR_input

**Что демонстрирует:**

Параллельность линий в диапазоне N_fft ∈ [1024..65536] — линейный режим работы
детектора. Расстояние между соседними линиями строго = 5 dB (входная разница SNR).
Это означает: детектор корректно **ранжирует** все сигналы по мощности.

При N_fft > 131072 параллельность нарушается: все линии сходятся к горизонтальному
плато ~55 dB. Форма насыщения различна для разных SNR_in: мощные сигналы (жёлтые)
уходят в плато при меньших N_fft, слабые (фиолетовые) сохраняют линейность дольше.
Пунктирные теоретические линии уходят вверх, тогда как измерения остаются у плато —
наглядная иллюстрация эффекта сайдлоб-загрязнения reference-bins.
