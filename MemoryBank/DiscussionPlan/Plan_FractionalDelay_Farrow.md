# План: Fractional-Delay генератор (структура Farrow)

> Ориентир: **Farrow** — переменная задержка через полином по μ, базисные фильтры фиксированы.  
> Задержка на луч задаётся в **микросекундах** (delay_us).

---

## 1. Цель

- Отдельный класс генератора с **дробной задержкой** на каждый луч.
- Задержка в **микросекундах** (массив `delay_us` на луч).
- Метод сдвига: **структура Farrow** (полином по дробной части μ, схема Горнера; basis filters фиксированы).
- Выход: только «сдвинутый сигнал + шум» (без TAU_STEP/TAU_RANDOM в первой версии).

---

## 2. Farrow — кратко

- Задержка в семплах: `delay = D + μ` (D — целая часть, μ ∈ [0, 1) — дробная).
- Импульсная характеристика интерполятора: полином по μ. Коэффициенты FIR представляются как полиномы по μ.
- **Структура Farrow**: несколько «базисных» FIR-фильтров (фиксированные коэффициенты); выход = полином от μ (обычно считают по схеме Горнера). При смене задержки пересчитывается только μ, фильтры не меняются — удобно для GPU и для переменной задержки в будущем.
- Источники: CCRMA JOS — «Farrow Structure for Variable Delay FIR Filters», «Farrow Structure Design Procedure».

---

## 3. Параметры и преобразование (все float)

| Параметр | Тип | Описание |
|----------|-----|----------|
| `delay_us` | **float** | Массив задержек на луч, **микросекунды**. |
| `sample_rate` | **float** | Частота дискретизации (Гц). |
| Преобразование | — | `delay_samples = delay_us * 1e-6f * sample_rate` → целая часть D (int), дробная μ (float). |

**Матрица коэффициентов 48×5**: 48 строк (дробные значения 0/48, 1/48, …, 47/48), 5 столбцов (5-точечная интерполяция Лагранжа). Все коэффициенты — **float**. Готовая матрица: [lagrange_matrix_48x5.json](lagrange_matrix_48x5.json) (в этой же папке); использовать при реализации и тестах. Точность можно повышать при доработке алгоритма.

Субсэмпельная точность: заложена в μ (например, 2 семпла + 0.3 → D=2, μ=0.3).

## 7. Алгоритм формирования — подробное описание (для переноса в описание методов)

### 7.1 Общая последовательность

1. Формирование сигнала по формуле (все антенны, параллельно).
2. Применение дробной задержки (матрица 48×5) по каждому лучу.
3. Добавление шума.
4. Область вне сигнала заполняется нулями.

### 7.2 Шаг 1 — Формирование сигнала по формуле

- **Вход:** параметры сигнала (частота, амплитуда, фаза, chirp, длительность и т.д.), число антенн, число отсчётов на антенну, `sample_rate` (float).
- **Действие:** для каждой антенны и каждого отсчёта по времени вычисляется комплексный (IQ) отсчёт по той же формуле, что и в FormSignalGenerator (экспонента с фазой, опционально chirp). Все антенны и отсчёты считаются в одном проходе (один kernel или цикл).
- **Выход:** буфер комплексных float (real, imag) размером `num_beams * num_samples`. Формат: луч за лучом — `buffer[beam_idx * num_samples + sample_idx]`.

### 7.3 Шаг 2 — Применение задержки (48×5)

- **Вход:** массив задержек `delay_us[]` (float) по лучам, `sample_rate` (float), матрица коэффициентов 48×5 (float), буфер сигнала из шага 1.
- **Преобразование задержки:** для каждого луча `delay_samples = delay_us[b] * 1e-6f * sample_rate`; целая часть `D = (int)floor(delay_samples)`; дробная часть `μ ∈ [0, 1)`. Номер строки матрицы: `lagrange_row = (uint)(μ * 48) % 48` (0…47).
- **Интерполяция:** для каждого выходного отсчёта с индексом `sample_idx` в луче `beam_idx`: центр чтения `center = sample_idx - D`. Берутся 5 отсчётов: индексы `center-1`, `center`, `center+1`, `center+2`, `center+3`. Коэффициенты — строка матрицы `lagrange_row` (5 float). Выходной отсчёт = сумма по k: `L[k] * input[center-1+k]` (отдельно real и imag). За границами массива (индекс &lt; 0 или ≥ num_samples) подставляется 0.
- **Результат:** перезаписывается во временный или выходной буфер (при IN-PLACE — через копирование temp → основной буфер, как в LCH-Farrow01).

### 7.4 Шаг 3 — Добавление шума

- К сдвинутому сигналу по каждому отсчёту (и по каждой антенне) добавляется комплексный шум (например, два независимых нормальных float для real и imag, с заданной дисперсией/уровнем). Параметры шума задаются отдельно (уровень, опционально seed).

### 7.5 Шаг 4 — Область вне сигнала

- Точки, в которых после сдвига «нет» сигнала (индекс чтения за пределами [0, num_samples) для любой из 5 точек интерполяции), уже дают 0 за счёт подстановки нуля при чтении (см. шаг 2). Дополнительно при необходимости можно явно обнулить начальный и конечный «хвосты» по длительности сигнала; иначе достаточно соглашения: вне окна интерполяции = 0.

### 7.6 Краткая формулировка для спецификации

*Сигнал по формуле (все антенны, float) → применение дробной задержки по delay_us (48×5, float) по каждому лучу → добавление шума (float) → вне интервала отсчётов при интерполяции значения равны 0.*
