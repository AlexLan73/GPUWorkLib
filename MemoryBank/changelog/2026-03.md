## 2026-03-09

### DrvGPU — External Context Integration (ROCm 7.2+, gfx1201 + gfx908)

**Паттерн**: все слои DrvGPU теперь поддерживают внешние GPU-хэндлы с `owns_resources_=false`.

- **ROCmCore**: добавлен `owns_stream_` (bool), `InitializeFromExternalStream()`, `ReleaseResources()` только вызывает `hipStreamDestroy` при `owns_stream_=true`
- **ROCmBackend**: `InitializeFromExternalStream(int, hipStream_t)` — создаёт `ROCmCore` с флагом `owns_stream_=false`
- **HybridBackend**: `InitializeFromExternalContexts(int, cl_context, cl_device_id, cl_command_queue, hipStream_t)` — делегирует в `OpenCLBackend::InitializeFromExternalContext` + `ROCmBackend::InitializeFromExternalStream`
- **DrvGPU**: приватный `ExternalInitTag` конструктор + 3 static factory:
  - `CreateFromExternalOpenCL(idx, ctx, dev, q)` — OpenCL
  - `CreateFromExternalROCm(idx, stream)` — ROCm/HIP
  - `CreateFromExternalHybrid(idx, ctx, dev, q, stream)` — Hybrid
- **Тесты**: 18 новых тестов в 3 файлах (по 6 в каждом), все проверяют non-ownership и выживание ресурсов после `~Backend`/`~DrvGPU`
