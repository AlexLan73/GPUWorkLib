### 🏆 Filters Module — Stage 1 MVP DONE!

- ✅ **Модуль `filters`** — полная реализация FIR + IIR GPU фильтрации
  - 16 C++ файлов: types, kernels (2 FIR + 1 IIR), classes, ROCm stubs, tests
  - FIR: direct-form, 2D NDRange (channels, points), __constant/__global авто-выбор
  - IIR: biquad cascade DFII-T, все секции в одном kernel, 1D NDRange (channels)
  - `filters.lib` собрана (MSVC 2022, Release)
- ✅ **Python bindings** — `py_filters.hpp` (FirFilter, IirFilter)
  - `gpuworklib.cp312-win_amd64.pyd` собран
- ✅ **Тесты PASSED** (RTX 2080 Ti, OpenCL 3.0, driver 581.42):
  - C++ FIR: err = 1e-6 (порог 1e-3)
  - C++ IIR: err = 1e-6 (порог 1e-3)
  - Python FIR vs scipy: err = 4.77e-7
  - Python IIR vs scipy: err = 1.31e-6
- ✅ **4-panel plot**: `Results/JSON/test_filters_stage1.png`
- ✅ **Интеграция**: root CMake, src/CMakeLists, main.cpp, Python bindings
