### Техническое решение:
- `ROCmGPUContext` определён перед `#include py_*_rocm.hpp` в bindings.cpp
- Память: через `backend->MemcpyDeviceToHost()` + `backend->Free()` (не raw HIP!)
- Filters/LchFarrow: `ProcessFromCPU()` — внутренний upload на GPU
- Heterodyne/Statistics: CPU-in/CPU-out API — нет ручного управления памятью
- Все biнdинги в `#if ENABLE_ROCM` блоке → компилируются только на Linux+AMD

### Сборка:
```bash
cmake -B build/debian-radeon9070 -DBUILD_PYTHON=ON
cmake --build build/debian-radeon9070 -j4
# Результат: build/.../python/gpuworklib.cpython-313-x86_64-linux-gnu.so
```

### Проблемы и решения:
1. **`-fPIC` для HIP объектов**: статические lib с HIP не могут линковаться в `.so` без `-fPIC`
   - Фикс: `POSITION_INDEPENDENT_CODE ON` в statistics CMakeLists
   - Фикс: `CMAKE_POSITION_INDEPENDENT_CODE ON` глобально в root CMakeLists
2. **pybind11 не установлен**: `pip install pybind11 --break-system-packages`
3. **`BUILD_PYTHON=OFF` по умолчанию**: нужно `-DBUILD_PYTHON=ON`
