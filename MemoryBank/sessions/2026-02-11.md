- ✅ `Process()` — интеграция с `BatchManager`
- ✅ `CalculateBytesPerAntenna()` — формула: `n_point*8 + 3*nFFT*8 + 128`
  - 3x nFFT = input + output + temp buffer clFFT!
- ✅ `ProcessBatch()` — обработка одного batch антенн
- ✅ `ReallocateBuffersForBatch()` — динамическое перевыделение буферов + FFT план
- ✅ `ExecuteFFT()` — поддержка temp buffer
- ✅ `ReleaseResources()` — освобождение temp buffer

**`modules/fft_maxima/tests/test_large_batch.hpp`** (НОВЫЙ):
- ✅ Тест 256 × 1,300,000 точек
- ✅ Генерация данных с разными частотами
- ✅ Валидация первых 10 антенн (CPU vs GPU)
- ✅ Проверка antenna_id после batch сборки

#### Ключевые находки:

1. **clFFT temp buffer**: clFFT требует временный буфер размером ~`batch * nFFT * 8`!
   - Это НЕ документировано явно
   - Без temp buffer — ошибка `CL_MEM_OBJECT_ALLOCATION_FAILURE (-4)`

2. **memory_limit = 25%**: Оптимальное значение для учёта overhead clFFT
   - 70% вызывает OOM даже при batch=37
   - 25% работает стабильно (batch=13)

3. **Mirror bin**: При ONE_PEAK режиме GPU может найти пик в "зеркальной" позиции (nFFT - bin)
   - Частота совпадает — это правильно
   - Bin корректируется через mirror при валидации
