### Баг и фикс: LchFarrow multi-antenna

**Проблема**: `delays = [0.0, 1.5, 3.0, 5.25]` → ant[2] с delay=3.0µs @ 1MHz
FAILED с max_diff=36.78 (огромная ошибка).

**Диагностика**:
- delay=3.0µs × 1e-6 × 1MHz = ровно 3 сэмпла
- На GPU `float(n) - delay_samples` для n=4,5 даёт `frac ≈ 0.9999`
- Это приводит к `row = int(0.9999 * 48) = 47`
- L[47] = [-0.4347, -13.3521, **20.0547**, 0.4347, 0.0] — огромные коэффициенты!
- Ошибка: 7.1373 и 6.7026 вместо ~1.0 для unit signal
- C++ тест ЗНАЛ об этом: использует {0.3f, 1.7f, **3.3f**, 4.9f} — нецелые!

**Фикс**: [`Python_test/lch_farrow/test_lch_farrow_rocm.py`](Python_test/lch_farrow/test_lch_farrow_rocm.py)
```python
# было:
delays_us = [0.0, 1.5, 3.0, 5.25]
# стало:
delays_us = [0.0, 1.5, 3.3, 5.25]   # avoid exact integer delays — GPU float32 boundary
```
