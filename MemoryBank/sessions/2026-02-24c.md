## 🔧 Технические детали

### Формат парсинга stdout
ConsoleOutput выводит: `[HH:MM:SS.mmm] [INF] [GPU_00] [Stats ROCm] message`

Regex паттерны:
- Тест: `r'\[(\+|X)\]\s+(.+?)\s+\.\.\.\s+(PASSED|FAILED)'`
- Итог: `r'Results:\s*(\d+)/(\d+)\s+passed'`
- Speedup: `r'Speedup\s*:\s*([\d.]+)x'`

### Ключевое отличие NumPy vs стандарт
`ref_median_mag` использует `sorted[n//2]` (как C++ `mags[n/2]`), а НЕ среднее двух средних элементов. Для n=1024: index 512 → value 513.
