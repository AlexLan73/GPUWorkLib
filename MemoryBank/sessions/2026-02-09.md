## 🎯 Что сделали

### 1. Отладка FFT (spectrum_maxima_finder)
- **Проблема**: Access Violation в `clfftEnqueueTransform` (0x0000000000000060)
- **Причина**: `clReleaseEvent()` вызывался ДО использования event как wait dependency
- **Решение**: Переместить release ПОСЛЕ передачи event

### 2. GPUProfiler — исправление формата
- **Проблема**: Показывались абсолютные timestamp (огромные числа)
- **Решение**: Вычисляем дельты и показываем в миллисекундах

### 3. Logger — путь к файлам
- **Проблема**: Файлы создавались с "92" вместо разделителя пути
- **Причина**: `std::filesystem::path::preferred_separator` (wchar_t) выводился как число
- **Решение**: Использовать `std::filesystem::path` с `operator/=`

### 4. Logger — формат записей
- **Было**: `2026-02-09 21:17:52.123 [34316] [@0] INFO ...`
- **Стало**: `2026-02-09 21:17:52.123 INFO ...`
- **Решение**: Кастомный `plog::DrvGPUFormatter`

### 5. Logger — связь с конфигом
- **Связали**: `DefaultLogger::Initialize()` проверяет `GPUConfig::IsLoggingEnabled(gpu_id_)`
- **Источник**: поле `is_logger` в `configGPU.json`

### 6. MemoryBank — создание структуры
- Создана полная структура для ведения проекта
- Спецификации всех планируемых модулей
- Система задач и changelog
