### Исправленные баги

#### 1. `offsets_buf_` пропущен в move constructor/operator=
**Файл**: `modules/statistics/src/statistics_processor.cpp`

```cpp
// Move ctor: добавлен
, offsets_buf_(other.offsets_buf_)
// ...
other.offsets_buf_ = nullptr;
```

Double-free при перемещении StatisticsProcessor — без переноса буфер оставался в moved-from и освобождался оба раза.

#### 2. PIE несовместим с HIP fat binary
**Файл**: `src/CMakeLists.txt`

```cmake
if(ROCM_ENABLED)
    target_link_options(GPUWorkLib PRIVATE -no-pie)
endif()
```

HIP `.hip.o` объекты содержат `.hipFatBinSegment` с `R_X86_64_32` relocations → incompatible с PIE. Линковка падала с "не может использоваться при создании объект PIE".

#### 3. "pure virtual method called" при завершении
**Файл**: `DrvGPU/services/console_output.hpp`

```cpp
~ConsoleOutput() {
    Stop();  // MUST be in derived class dtor!
}
```

**Причина**: `AsyncServiceBase::~AsyncServiceBase()` вызывает `Stop()` → worker thread просыпается и вызывает `ProcessMessage()` через vtable → но vtable уже переключён на базовый класс → pure virtual stub → terminate().

**Правило**: Если base class destructor вызывает виртуальные функции через Stop/join thread → ОБЯЗАТЕЛЬНО вызывать Stop() в DERIVED class destructor!

#### 4. Группа render
