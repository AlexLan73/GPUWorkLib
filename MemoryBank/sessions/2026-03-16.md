## Пайплайн

```
Upload(Y, U) →
  CovarianceMatrixOp (R = Y*Y^H/N, rocBLAS) →
  DiagonalLoadRegularizer (R += mu*I) →
  CaponInvertOp (R^{-1}, rocSOLVER POTRF+POTRI) →
  ComputeWeightsOp (W = R^{-1}*U, rocBLAS) →
  CaponReliefOp (z[m] = 1/Re(u^H*W), hiprtc) или
  AdaptBeamformOp (Y_out = W^H*Y, rocBLAS) →
Download
```
