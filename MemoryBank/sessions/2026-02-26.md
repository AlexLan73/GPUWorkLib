## Детали изменений

### TASK-1 P0 — Параллельная tree-reduction (30-60× для post_kernel)
- `post_kernel` (TwoPeaks) и `post_kernel_one_peak` (OnePeak)
- Последовательный `if (lid==0) { for j<local_size }` → параллельная tree-reduction
- `for (stride=128; stride>0; stride>>=1) { if(lid<stride) ... barrier(); }`
- O(256) → O(log₂256=8 шагов)

### TASK-2 P1-C — native_sqrt()
- Все `sqrt(x*x + y*y)` → `native_sqrt(x*x + y*y)` в обоих .hpp файлах
- Затронуто: post_kernel (TwoPeaks+OnePeak+WRITE_FOUR), compute_magnitudes

### TASK-3 P1-A — Bitwise div/mod в pre-callback
- `PreCallbackHeader.padding1` → `nFFT_log2`
- Kernel: `inoffset / nFFT` → `inoffset >> nFFT_log2`
- Kernel: `inoffset % nFFT` → `inoffset & (nFFT - 1)`
- C++ WritePreCallbackHeader: вычисляет log2(nFFT) и записывает в заголовок

### TASK-4 P1-B — padding_kernel 2D NDRange
- Заменён 1D `gid/nFFT, gid%nFFT` на `get_global_id(0)/(1)`
- Нет else-branch (output занулять clEnqueueFillBuffer до запуска)

### TASK-5 P2-A — LDS +1 padding
- `__local float local_*[256]` → `__local float local_*[257]` в post kernels

### TASK-6 P2-B — detect_all_maxima 2D NDRange
- Kernel: `gid/nFFT, gid%nFFT` → `get_global_id(0)/(1)`
- C++ dispatch: 1D → 2D: `global[2]={nFFT,beam_count}, local[2]={256,1}`

### TASK-7 P2-C — reqd_work_group_size(256,1,1)
- Добавлен к `post_kernel`, `post_kernel_one_peak`, `detect_all_maxima`

### TASK-8 P2-D — __restrict
- Все `__global T*` → `__global T* restrict` во всех kernels (оба файла)

### TASK-9 P3-A — prefix_sum LDS +1
- C++: `SCAN_BLOCK_SIZE * sizeof(uint32_t)` → `(SCAN_BLOCK_SIZE+1) * sizeof(uint32_t)`
- Добавлен комментарий в kernel source
