## 🗂️ ТЕМА 1: Farrow Fractional Delay — Документация

### Что сделано
- Создан файл `Doc_Addition/Info_FarrowFractionalDelay.md` — полная документация
- Объяснено ЗАЧЕМ Farrow нужен для ЛЧМ-радара с фазированными решётками (дробная задержка в отсчётах)
- Объяснена интерполяция Лагранжа 5-точечная и матрица коэффициентов 48×5
- Задокументированы два эквивалентных подхода:
  - **Вариант A** — через mu от delay_samples (используется в реальном ядре ✅)
  - **Вариант B** — через frac от read_pos (эквивалентен, но иначе записан)
- Подтверждено: реальное ядро использует Вариант A, тесты проходят (err < 1e-3)
- Предоставлен шаблон OpenCL ядра с TODO-маркерами для реализации другим AI
- Предоставлен 5-уровневый план верификации (unit → reference → LFM-specific → load → E2E)

### Ключевые инсайты

**Матрица 48×5:**
- 48 строк = квантованные шаги дробной задержки (шаг = 1/48)
- 5 столбцов = коэффициенты Лагранжа для 5-точечной интерполяции
- Выбор строки: `row = (uint)(mu * 48) % 48`, где `mu = delay_samples - floor(delay_samples)`

**Вариант A (реальное ядро):**
```c
float mu = delay_samples - floor(delay_samples);
uint row = (uint)(mu * 48.0f) % 48;
// coeffs[row][0..4] — коэффициенты интерполяции
int base = (int)floor(delay_samples) - 2;
// sample = sum(coeffs[row][k] * x[base + k]) для k=0..4
```

## 🗂️ ТЕМА 2: AI-Driven FIR Filter Pipeline

### Что исследовано
- Существующий Python API GPUWorkLib готов на ~90% для AI-DSP пайплайна
- ScriptGenerator уже умеет: text DSL → OpenCL kernel → GPU
- SignalGenerator, FFTProcessor, SpectrumMaximaFinder — у всех есть Python биндинги
- `generate_from_string()`, `set_params_from_string()` уже существуют

### Спроектированная архитектура
```
Текстовая команда → AI (LLM) → JSON параметры → scipy FIR design → GPU pipeline → валидация + графики
```

### Исследованные бесплатные AI бэкенды

| Бэкенд | Тип | Модель | Установка |
|--------|-----|--------|-----------|
| Groq API | Cloud, free | llama-3.3-70b-versatile | `pip install groq` |
| Ollama | Offline | qwen2.5-coder:7b | `ollama pull qwen2.5-coder:7b` |
| Оба | — | — | Совместимы с OpenAI SDK |

### Что отсутствует для полного GPU FIR
1. `fir_filter.cl` — OpenCL ядро для FIR свёртки (прямая форма, float2 комплексный)
2. `PyFIRFilter` — pybind11 обёртка в `gpu_worklib_bindings.cpp`
3. Регистрация Python биндингов в `PYBIND11_MODULE`

### Созданный файл `Python_test/test_ai_fir_demo.py`

**Что умеет:**
1. `MODE="none/groq/ollama"` — переключаемый AI бэкенд
2. LLM парсит текстовый запрос → JSON с параметрами фильтра
3. `scipy.signal.kaiserord` + `firwin` → коэффициенты FIR
4. `gpuworklib.SignalGenerator` генерирует тестовые синусоиды на GPU
5. FIR применяется (сейчас CPU/scipy, TODO: GPU FIRFilter)
6. `gpuworklib.FFTProcessor` анализирует спектр на GPU
7. Валидация: проверка затухания, проверка подавления
8. 4-графиковая matplotlib фигура: АЧХ + коэффициенты + временная область + сравнение спектров

**Режимы запуска:**
```bash
# Без AI (работает сразу):
MODE="none"  # в начале скрипта

# С Groq (облако, бесплатно):
pip install groq
export GROQ_API_KEY="gsk_..."
MODE="groq"

# С Ollama (оффлайн):
ollama pull qwen2.5-coder:7b
MODE="ollama"
```
