## Часть 2 — GPU Median Sort (rocprim)

### Удалены конфликтующие пакеты HIP 5.7
```bash
sudo dpkg --remove --force-depends libamdhip64-dev libhiprtc-builtins5 libamdhip64-5
```
- `/usr/include/hip/` (HIP 5.7 headers) — удалён
- Теперь единственный HIP — `/opt/rocm-7.2.0/` (HIP 7.2)
- `hipcc` работает: ldd не зависит от удалённых библиотек

### CPU sort → GPU segmented radix sort
Данные: 256 лучей × 1,300,000 float — CPU sort давал ~2000ms, GPU даст ~30ms.

**Решение:** `rocprim::segmented_radix_sort_keys` — все 256 лучей параллельно в одном вызове.

**Архитектура (2 файла):**
- `statistics_sort_gpu.hip` — HIP compiler (clang++), только rocprim вызов
- `statistics_processor.cpp` — g++ (host logic), вызывает gpu_sort::ExecuteSort
- `statistics_sort_gpu.hpp` — объявления C++ для обоих файлов

**Новые буферы:**
- `offsets_buf_` — device array `[0, n_point, 2*n_point, ..., beam*n_point]`
- `sort_temp_buf_` — rocprim temp storage (размер через QuerySortTempSize)

**CMakeLists.txt statistics:**
- `enable_language(HIP)` + `set_source_files_properties(.hip PROPERTIES LANGUAGE HIP)`
- `find_package(rocprim QUIET)` + `FATAL_ERROR` если не найден
- `target_link_libraries(... roc::rocprim)`

✅ Сборка: `statistics_sort_gpu.hip` компилируется HIP компилятором, 0 errors
